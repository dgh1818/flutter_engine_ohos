# Changelog: Flutter 3.41 to Flutter 3.44

The version differences from Flutter 3.41 to Flutter 3.44 mainly cover API deprecations and renames, class visibility adjustments, scroll widget property changes, and the Android build toolchain migration. Developers need to pay attention to the changes that require adaptation.
